## Questions you should be able to answer

**Is it AI?** The offline demo uses rules and templates. The optional Google ADK extension uses a model, but needs separate setup and verification.

**Does it connect to LinkedIn?** No. You manually paste one latest prospect reply. There is no scraping or automatic sending.

**What did you contribute?** Explain the workflows and examples you actually reviewed. The implementation was built with AI assistance. Do not claim handwritten code or client deployments you did not perform.

**Why open source?** Other practitioners can add fictional edge cases and improve the rules; developers can inspect the logic and contribute small changes.

**How accurate is it?** The included tests and development examples pass. They are not unseen data, so we cannot infer real-world accuracy. Sarcasm, multilingual replies and indirect language remain limitations.

## Before recording

Open the standalone demo, keep browser zoom at 100%, rehearse once, use fictional messages, close unrelated tabs and avoid showing account credentials. A simple screen recording with your voice is enough; do not imply it was recorded at Google or after selection.
