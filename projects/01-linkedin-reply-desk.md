# LinkedIn Reply Desk

**Hero project · working offline prototype**

## Problem
Prospect replies need different next actions, and a positive phrase can appear inside a decline.

## Try it
Open [the demo](../index.html) and choose LinkedIn Reply Desk in the sidebar.

Paste one latest prospect reply → inspect evidence and suggested action → edit → review → copy.

## Example
“Sounds good. Could you send more details?” → interested, with the matched phrases shown.

## Implemented
Six samples, editable input, intent labels, evidence, ambiguity handling, opt-out recommendation, editable drafts and JSON export.

## Scope and limitations
No LinkedIn integration, scraping, autonomous sending or production accuracy claim. Rules are English-only and incomplete.
